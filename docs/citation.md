# Citing SeroEpi

If you use **SeroEpi** in your research, surveillance analyses, or publications, please cite the software using the metadata below.

=== "BibTeX"

    ```bibtex
    @software{Stanton_SeroEpi,
      author       = {Stanton, Thomas David},
      title        = {{SeroEpi: A Python library for bacterial sero-epidemiology}},
      url          = {https://seroverse.github.io/SeroEpi/},
      repository   = {https://github.com/SeroVerse/SeroEpi},
      license      = {GPL-3.0-only}
    }
    ```

=== "APA"

    ```text
    Stanton, T. D. SeroEpi: A Python library for bacterial sero-epidemiology [Computer software]. https://github.com/SeroVerse/SeroEpi
    ```
